# 루미큐브 온라인 (실시간 2~4인 멀티플레이어)

Node.js + Express + Socket.IO 기반의 **실시간 온라인 루미큐브** 전체 프로젝트입니다.  
프론트엔드(`public/index.html`)와 실시간 게임 서버(`server.js`)가 하나로 묶여 있어 로컬 실행과 무료 클라우드 배포가 매우 간편합니다.

## 주요 기능
- **실시간 2~4인 온라인 멀티플레이**: 4자리 방 코드 생성 및 친구 초대, 부족한 자리는 AI 봇 추가 가능, 새로고침 재접속 지원
- **서버 권한 검증 (치팅 방지)**: 타일 더미와 각 플레이어의 패는 서버에만 저장되며, 턴 확정 시 서버가 30점 첫 등록과 모든 세트를 검증
- **턴당 40초 서버 타이머**: 모든 참가자에게 실시간 동기화, 시간 초과 시 자동 확정 또는 원복 + 페널티 처리
- **편의 조작 완비**:
  - **789**(연속) / **777**(숫자) 메이드 패 우선 정렬 (상대 턴에도 언제든 가능)
  - 내 패 좌클릭 메이드 패 자동 선택 & 드래그 배치
  - 누르는 즉시 선택 + **0.25초마다 뒤쪽 패 +1개** 추가 선택
  - 자유 배치 + 자석 스냅 + 인접 메이드 패 자동 이동 + 중간 끼워넣기 **`✂ 자동 분리`**

## 로컬에서 바로 실행하기
Node.js 18 이상이 설치되어 있어야 합니다.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 에 접속해 방을 만들고, 다른 탭이나 같은 네트워크의 스마트폰으로 방 코드를 입력해 바로 플레이할 수 있습니다.

## 인터넷에 무료로 배포하기 (Render / Railway / Fly.io)
1. 이 폴더를 GitHub 저장소에 올립니다.
2. [Render](https://render.com/)에서 **New → Web Service** 선택 후 저장소를 연결합니다.
3. 설정:
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
4. 배포 완료 후 발급된 `https://...onrender.com` 주소를 친구들에게 공유하면 어디서나 방 코드로 함께 플레이할 수 있습니다!
